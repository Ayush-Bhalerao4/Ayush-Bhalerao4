## About

I'm an AI/ML-focused engineer who also builds the full stack around the model — the API, the UI, the database — because a model nobody can query isn't a product yet.

Recent work spans graph neural networks for molecular property prediction, computer-vision-driven disaster risk scoring, and data dashboards people actually use to make decisions. I like projects with a clear before/after: a slower process made faster, a manual read made automatic, a black box made explainable.

Currently finishing my B.Tech and looking for a full-time **ML Engineer**, **AI Engineer**, or **Software Engineer** role — happy to relocate.
